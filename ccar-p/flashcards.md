# CCAR-P — Flashcard journal

Every mistake lands here as a card. The deck drives 30% of each daily quiz, so a mistake you make
today comes back until it stops being a mistake.

## Rules

| Rule | Value |
|---|---|
| Card created | On every wrong answer, including partially wrong multiple-response items |
| Retirement | **Two consecutive** correct answers |
| Reset | One wrong answer sends the streak back to 0, even on a card at 1/2 |
| Quiz mix | 30% of each 10-question quiz comes from open cards — so 3 of 10 |
| Re-ask form | Rephrased each time, different scenario, never the same wording twice |

The two-correct rule matters. One correct answer often means you recognised the question, not that
you understood the principle. Rephrasing on re-ask is what separates the two.
